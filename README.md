## 📌 Featured Projects

### 🧮 [Advanced LLM Reasoning](https://github.com/minquan-alt/AdvancedLLMReasoning)
Improving math reasoning of a **1B-parameter model (Llama-3.2-1B)** under tight compute (single RTX 4090).
* QLoRA SFT (4-bit NF4) on OpenMathInstruct-1 → GRPO with a rule-based Outcome Reward Model.
* Iterated data formats (masking, instruction, Llama 3.2 chat template + Python blocks) and added a **code-execution inference pipeline**.
* **GSM8K: 44.4% → 51.6%** · **MATH500: 23.9% → 26.0%**
* `PyTorch` `Transformers` `PEFT` `TRL` `bitsandbytes`

### 🤟 SignLearn – AI Sign Language Tutor ([code](https://github.com/minquan-alt/sudo2025))
Real-time sign language recognition & learning platform with gesture tracking and LLM-powered feedback. **2nd Runner-Up – Sudo Code 2025.**
* **My role:** RAG lead — knowledge base, Qdrant dual-collection retrieval + LLM reranking, Gemini 2.5 agent, LLM-as-Judge evaluation.
* **Retrieval:** Precision@5 0.66 · MRR 0.923 (P@5 0.58 → 0.66 vs. single collection)
* **Generation (LLM-as-Judge):** 4.68/5 response quality · 4.87/5 hallucination check · 0.75 generation accuracy
* `FastAPI` `ONNX` `MediaPipe` `Gemini 2.5` `LangChain` `Qdrant`

### 📈 [Demand Forecasting System](https://github.com/minquan-alt/DemandForecasting)
